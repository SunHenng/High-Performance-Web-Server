About

This web server is built with modern C++ and uses the following components:

  • Reactor Pattern: Event-driven architecture for handling concurrent connections
  • epoll: Linux I/O multiplexing for high performance
  • Thread Pool: Parallel processing for CPU-intensive tasks
  • HTTP Parsing: Built-in HTTP/1.1 request and response handling
  • Static File Serving: Efficient delivery of web content
  • User Authentication: Login and registration backed by MySQL
